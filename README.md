# ナンバープレート

[ゲームをプレイ](./Game/index.html)

**車を運転している時に考えてるアレ**

ナンバープレートに並ぶ数字を使って、答えを **10** にする計算パズルです。
数字を並べ替えたり、演算記号を組み合わせたりして、制限時間内に解きましょう。

Version 1.0.1 / Produced by DS-Works

## はじめ方

1. `Game` フォルダー内の [index.html](Game/index.html) を、ChromeやEdgeなどのブラウザーで開きます。
2. タイトル画面をクリックします。
3. **10問・20問・50問・100問**から、挑戦する問題数を選びます。
4. 初めて遊ぶときだけ、第1問の前に遊び方のTipsが表示されます。「ゲーム開始」を押すと、制限時間がスタートします。

インストールやサーバーの起動は不要です。操作はマウスだけで行います。
ゲームのファイルを移すときは、`Game` フォルダーを丸ごと移してください。
Tipsを表示したかどうかは、ブラウザーに保存されます。タイトル画面右下の「データ削除」を押すと、保存した記録を消して、次回もう一度Tipsを表示できます。

## 基本ルール

- 出題される数字は2～4個です。**各数字を1回ずつ、すべて使って**10を作ります。
- 数字の順番は自由に入れ替えられます。
- 使用できる記号は **＋・－・×・÷・(・)・√** です。
- **数字は必ず1桁ずつの値として扱います。** 隣り合った数字を、18や27などの複数桁の数として使うことはできません。
- 0に関する省略ルールを除き、数字の間には必要な演算記号をすべて入れてください。
- 1つの桁間に置ける記号は、**括弧を除いて最大2個**です。
- 計算結果が10になると自動的に正解となり、短いジングルの後で次の問題へ進みます。回答ボタンはありません。
- どの問題にも、10を作れる解法があります。

例えば、数字が **2・7・4・0** なら、並びを入れ替えて次のように解けます。

```text
7 × 2 − 4 ＋ 0 ＝ 10
```

### 計算の順番

括弧内を先に計算し、×・÷を＋・－より優先します。同じ優先順位の計算は左から行います。
計算途中で負の数や分数になっても構いません。

先頭の－は負の数を表し、先頭の＋は値を変えません。先頭に×・÷は置けません。

## 操作方法

「ドラッグ」は、マウスの左ボタンを押したまま動かし、目的の場所で離す操作です。

| やりたいこと | 操作 |
| --- | --- |
| 数字の順番を変える | 数字を別の数字の上へドラッグすると、2つの位置が入れ替わります。 |
| 記号を置く | 下部の記号一覧から、数字の前後や間へドラッグします。 |
| 記号を追加する | 配置済み記号の**左右の余白**へドラッグします。点線と背景色が出た側に追加されます。 |
| 配置済み記号を別の記号にする | 記号一覧から、配置済みの**四角いタイルの上**へドラッグします。 |
| 配置済み記号を移動する | その記号を、別の挿入位置へドラッグします。 |
| 記号一覧を使って置き換える | 配置済み記号を、下部の記号一覧の目的の記号へドラッグします。元の位置の記号が置き換わります。 |
| 記号を消す | 配置済み記号を右クリックするか、ナンバープレートの外へドラッグします。 |
| 式を最初の状態へ戻す | 「この問題をリセット」をクリックします。 |
| 音を切り替える | 右上の「♪」ボタンをクリックします。 |

記号の追加と置き換えは、ドロップする場所で決まります。**タイル上は置き換え、左右の余白は追加**です。
記号数の上限を超える操作など、無効な配置は反映されません。

## 0の扱い

加減算では、0の前後の記号を一部省略できます。ただし、**0を挟んでいても、0以外の数字同士には演算記号が必要**です。
以下の表記も、複数桁の数として読んでいるわけではありません。

| 入力した式 | 扱い |
| --- | --- |
| `5＋05` / `50＋5` | どちらも10で正解です。 |
| `505` | 5同士の間に記号がないので無効です。 |
| `1＋405` | 4と5の間に記号がないので無効です。 |
| `1＋40＋5` | 1＋4＋5として10で正解です。 |
| `1＋18` | 1と8の間に記号がないので無効です。`1＋1＋8` としてください。 |
| `8−02` / `80−2` | どちらも8−2として6になります。 |
| `8＋02` | 8＋2として10で正解です。 |

**×0は通常どおり0を掛けます。** 例えば、`8−0×2` の結果は8です。

**数字0を掛けた部分（`0×1`、`3×0` など）は、存在しない値として扱います。** その前後では、0のときと同じように＋を省略できます。

| 入力した式 | 扱い |
| --- | --- |
| `0×1 2×5` / `2×5 0×1` | どちらも0×1を無視し、2×5＝10で正解です。 |
| `1 0×2 5` | 0×2を無視すると1と5の間に記号がないので無効です。 |

最初の表示やリセットだけで正解になることはありません。数字や記号を操作すると正解判定が行われます。

## √と÷0の特別ルール

### 平方根「√」

√は、直後の数字または括弧内の式の平方根を求めます。**結果が整数になる場合だけ**適用されます。

- `√9` は3です。
- `√(9＋7)` は4です。
- `√2` のように結果が整数にならない場合や、負の数の平方根には、√の上に赤い✕が表示されます。その√は適用せず、元の値で計算を続けます。

### 0による除算「÷0」

0では割れません。このゲームでは、該当する÷に赤い✕を重ね、**割る前の値をそのまま使って**計算を続けます。

```text
5 ÷ 0 ＋ 5 ＝ 10
```

括弧内の計算結果が0になった場合も同じです。赤い✕の付いた記号があっても、残りの式が正しく計算できれば、その結果で判定します。

## プレートと計算結果の見方

- 計算に使うのは、プレート下段の大きな数字だけです。地名・上段の分類番号・ひらがなは計算に使いません。
- プレートの色は、実際のナンバープレートのように白・黄・緑・黒の4種類から毎問ランダムに変わります。色の違いは計算には関係ありません。
- 中央の短いハイフンは、ナンバープレートの区切りです。**減算記号ではありません。** 計算の－は、下の記号一覧から配置してください。
- 4桁に満たない数字は、上の桁を0で埋めて「・」で表示します。この「・」も数字の0として、並べ替えや計算に使います（例：・355 → ・×3＋5＋5＝10）。
- 「・」で表示されるのは先頭から続く0だけです。並べ替えて途中に移った0は「0」と表示されます（例：3055）。
- プレートの右側の「＝」の後に、現在の計算結果が表示されます。
- 結果欄の赤い✕は、記号不足・括弧の不一致などで、式全体を計算できない状態です。
- 記号の背景色は、＋が赤、－が水色、×が黄色、÷が黄緑、√が紫です。

## 制限時間とゲームの終了

1問の制限時間は **30秒** です。画面上部のバーと数字で残り時間を確認できます。

- 正解すると、次の問題の制限時間は30秒に戻ります。
- 式をリセットしても、残り時間は戻りません。
- 時間が0になるとゲームオーバーです。
- 選んだ問題数をすべて正解するとクリアです。
- 問題は進むほど難しくなり、同じプレイ中に同じ問題は出題されません。

結果画面の「もう一度あそぶ」で同じ問題数に再挑戦できます。問題数を変えたいときは「タイトルへ」で戻ってください。

## サウンド

タイトル・プレイ・クリア・ゲームオーバーで、それぞれ異なる落ち着いたBGMが流れます。
最初のクリックから再生が始まり、右上の「♪」ボタンでBGM・効果音・正解ジングルをまとめてオン／オフにできます。

左クリックでは決定音、記号の配置・移動・置き換えでは設置音、記号の削除ではドロップ音が鳴ります。

音が出ない場合は、ゲーム画面を一度クリックし、「♪」ボタンがOFFになっていないか、ブラウザーや端末が消音されていないか確認してください。
