# 設計書

本ドキュメントに、作成・実装の基準となる設計内容を記載します。

## 設計内容の記録

以後、設計に関わる指示は本ドキュメントに追記します。

## プラットフォームとファイル構成

- プラットフォームは HTML + JavaScript とします。
- 生成物は、リポジトリルートの `/Game` フォルダ内に格納します。
- 初期状態では、以下の3ファイルを用意します。
  - `index.html`
  - `game.js`
  - `style.css`
- 開発進捗に応じて、ファイルを分割する可能性があります。

## コーディングスタイル

JavaScript のコーディングスタイルは、全プロジェクト共通の C# のコーディングスタイルを踏襲します。JavaScript の構文・動作上必要な例外は、共通規約の JavaScript 向け注意事項に従います。

## ゲームの基本ルール

- 2桁～4桁の数値を出題します。各桁は0～9で、最上位桁は0にしません。
- 桁数はランダムとし、難易度が上がるほど桁数が大きくなる傾向にします。
- 出題された数値を1桁ずつ分解し、その順番を自由に入れ替えられます。
- 各桁を1回ずつすべて使い、数字の連結は行いません。
- `＋`、`－`、`×`、`÷`、`(`、`)`、`√` を自由に挿入し、計算結果を10にします。
- √は、結果が整数になる場合だけ適用できます。式や√の結果にも、この条件を満たす限り適用できます。
- 途中計算の分数・負数は許容します。0除算は適用せず左辺の値を保持し、負数の平方根は適用しません。
- 必ず10を作る式が存在する数値だけを出題します。

## 問題の事前生成と難易度

- 19～9999の整数から、上記ルールで10を作れる値を事前に抽出します。
- 各値の難易度は、最小限の並べ替え・記号の使用を基準として求めます。
- 難易度の加点は以下のとおりです。
  - 数字1つにつき1ポイント。
  - `＋`、`－`、`(`、`)` は各1ポイント。
  - `×`、`÷` は各2ポイント。
  - `√` は1つにつき4ポイント。
  - 数字の並べ替えにつき1ポイント。
- 例：9999は `(√9 × √9) ÷ 9 ＋ 9 = 10` とできます。
  - 数字4つで4ポイント、＋と括弧2つで3ポイント、×÷で4ポイント、√2つで8ポイント、並べ替えなしで0ポイント、合計19ポイントです。
  - この式は例であり、より少ない加点で解ける場合は、その解を基準にできます。
- 出題用データは難易度の昇順に並べ、難易度に応じて取得します。
- 今回の `/Game/Question.csv` は、出題可能な値を数値の昇順で並べたカンマ区切りデータとします。難易度の算定と難易度順データの作成は後続の実装で行います。
- CSVの表示が長い1行の途中で途切れることを避けるため、値は1列・1行に1つ、ヘッダーなしで格納します。

## 出題タイプ

- 10問・20問・50問・100問の4タイプを用意します。
- 出題数に応じて難易度が上がるようにします。
- 問題として選ぶ値にはランダムな揺らぎを持たせます。

## 画面・入力・画面遷移

- 基準解像度は1280×720、アスペクト比は16:9とします。ウィンドウに合わせて同比率で拡大縮小します。
- 入力はマウス操作とタッチ操作に対応します（詳細は「スマートフォン・タッチ操作への対応」）。
- タイトル画面 → プレイ画面 → クリア画面またはゲームオーバー画面の流れとします。
- タイトルは「ナンバープレート」、副題は「車を運転している時に考えてるアレ」とします。
- タイトル画面をクリックすると、10問・20問・50問・100問の選択ポップアップを表示します。選択すると開始します。

## プレイ画面と操作

- 車のナンバープレートを模した下地に、2～4桁の数値を大きく表示します。
- 4桁分の表示枠を用意し、2桁ごとの区切りは短いハイフンとします。4桁に満たない値は上位桁を0で埋めます（詳細は「4桁未満の問題の上位桁」）。
- 最上位から続く0は「・」、それ以外の0は「0」と表示します。
- 数値の左側にランダムなひらがな1文字、上に地域名と分類番号をランダム表示します。対象は後述のテーブルに従います。
- プレートの下に `＋`、`－`、`×`、`÷`、`(`、`)`、`√` の四角いアイコンを表示します。
- 数字はドラッグで順番を入れ替えます。
- 記号はアイコンからドラッグして挿入します。数字の前後にも配置でき、数字と数字の間には括弧を除いて最大2つまでとします。上限を超える挿入・移動は無効とします。括弧を上限に数えないことで、既存8,866問をすべて配置可能にします。
- 記号の挿入に応じてプレートを左右に拡張し、ひらがなは常に左端に追従させます。
- 配置済みの記号もドラッグで移動でき、右クリックで削除します。
- `＋` は加算で、先頭では値を変えません。`－` は減算で、先頭では負値にします。
- `×`、`÷` は乗算・除算で、先頭への配置は無効とします。
- 括弧内を優先し、乗除算を加減算より優先します。数字を隣接させても連結はしません。
- `√` は後続の数字または括弧内の式に適用します。結果が整数にならない場合は記号の上に赤い✕を表示し、その平方根操作を無視して元の値で計算します。
- プレート外の右に `=` と現在の計算結果を表示します。アイコン群の右にも同じ結果を表示します。計算不能時は赤い✕とします。
- 結果が10になったら短いジングルを鳴らし、次の問題に進みます。

## 制限時間・終了・評価

- 各問題の制限時間は一律30秒で、毎問30.0秒にリセットします。
- 上部に時間とともに減少する横長プログレスバーと、小数第1位までの残り秒数を表示します。
- 0秒になったらゲームオーバー画面、選択した問題数をすべて正解したらクリア画面に遷移します。
- クリア画面は花火演出と「クリアおめでとう」、ゲームオーバー画面は「ゲームオーバー」を表示します。
- 両画面で見出しの下に `IQ XXX` を大きく表示します。ゲーム内の評価値であり、0～20問は後述の指定表を使用します。21問以上は20問：120、50問：150、100問：200を結ぶ区間で線形補間し、整数に丸めます。

## 難易度付き問題テーブルと出題範囲

- `/Game/Question.csv` をヘッダーなしの「数値,難易度値」の2列へ変更します。従来の数値昇順・1列形式を置き換えます。
- 難易度値の昇順、同点の場合は数値の昇順でソートします。これを「問題テーブル」と呼び、インデックスは0始まりとします。
- 難易度算定での並べ替えは、元の数値と比べて数字が変わった位置の個数を1位置1ポイントとし、同じ数字の交換は加点しません。
- 記号数は、演算の優先順位に従い不要な括弧を省いた式で数えます。
- 1～20問目：第n問はテーブル `[(n−1)×200]～[n×200−1]` の200件からランダムに選びます。1問目は `[0]～[199]`、10問目は `[1800]～[1999]`、11問目は `[2000]～[2199]`、20問目は `[3800]～[3999]` です。
- 21～50問目：`[4000]～[5999]` からランダムに選びます。
- 51～100問目：`[6000]～[最後]` からランダムに選びます。現在の末尾は `[8865]` です。
- 同じインデックスは1プレイ中に再出題しません。
- ローカルのHTMLを直接開いてプレイできるよう、CSVから生成した `questions.js` も `/Game` に格納します。CSV更新時は生成ツールで同期します。

## 記号を省略した桁間の計算（0に限定して訂正）

- 数字は例外なく1桁ずつの個別の値として扱い、複数桁の数には連結しません。
- 加算記号を省略できるのは、境界の直前または直後の数字が0の場合だけです。0以外の数字の間は、必要な演算記号をすべて配置しなければ計算・正解判定できません。
- 例：`5＋05`、`50＋5` は `5＋0＋5＝10` として計算します。記号がない `505` は、0以外の5同士の間に記号がないため無効です。
- 例：`118`、`1＋18`、`11＋8` は記号不足で無効です。`1＋1＋8＝10` で正解になります。
- 0は加減算では値を変えないものとして扱い、上記の省略時も加算と同じ優先順位にします。明示された `×0` は必ず乗算して0にします。`÷0` の表示・計算は次項に従います。
- `√` や開き括弧の前でも、0に接していない境界では演算記号を省略できません。計算した結果が0になる式を、数字0そのものの例外としては扱いません。
- 初期表示やリセットだけでは正解扱いにせず、数字の交換・記号の配置や移動・記号の削除が行われた後に正解判定します。クリックだけ、範囲外へのドロップ、無効な挿入では判定しません。
- 難易度には実際に配置する記号だけを加点し、省略した加算は0ポイントとします。既存8,866問の難易度を再算定し、問題テーブルとブラウザー用データを同期します。

## 0除算の扱い

- 除数が0になる場合、その除算は適用せず、該当する `÷` 記号に赤い✕を重ねて表示します。
- 割る前の値を保持して、残りの式を計算します。例：`5÷0＋5＝10`、`5÷0×2＝10` とします。
- 括弧内の計算結果などが0になった除数も同じ扱いにします。例：`9÷(1−1)＝9` とします。
- 除数を変更して0でなくなった場合は赤い✕を消し、通常の除算に戻します。他の箇所に記号不足などがあれば、式全体は引き続き計算不能とします。

## ナンバープレートのひらがな

- 国土交通省・東北運輸局の「ナンバープレートの見方」のかな文字一覧を参照します。
  - 出典：https://wwwtb.mlit.go.jp/tohoku/jg/jg-sub29_1.html （2026年10月30日確認）
- 現段階では用途を固定せず、登録自動車の全用途で使用されるひらがなの合計42文字から、毎問等確率で1文字を選びます。
- 対象：`あいうえかきくけこさすせそたちつてとなにぬねのはひふほまみむめもやゆよらりるれろわを`。
- 内訳は、事業用10文字、自家用29文字、貸渡用の「れ・わ」、駐留軍人・軍属私用等の「よ」です。英字は対象にしません。
- 「お・し・へ・ゐ・ゑ・ん」、濁点・半濁点付きの文字、小書き文字は使用しません。

## 地域名・分類番号のランダム表示

- `/Game/plate-data.js` に地域名138種類と分類番号のテーブルを格納します。富士山・知床など、複数の管轄にまたがる同じ地域名は重複させません。
- タイトル表示時と毎問の出題時に、地域名と分類番号をそれぞれ等確率で選びます。式を編集・リセットしても、その問題の表示は変えません。
- 分類番号は数字のみの登録自動車用を対象に、1桁の0～9、2桁の00～99、3桁の000～999の合計1,110通りを文字列で保持します。先頭の0は省略しません。
- 先頭数字の分類は、1が普通貨物、2が乗合、3が普通乗用、4・6が小型貨物、5・7が小型乗用、8が特種、9が大型特殊、0が建設機械です。
- 数字以外の英字入り分類番号は今回は含めません。従来の1・2桁も含む制度上の範囲を表示対象とし、各地域における個々の番号の実際の払い出し実績や、地域名・分類番号・ひらがなの組み合わせの発行実績までは再現しません。
- 参照資料（2026年10月30日確認）：
  - 国土交通省「地域名表示一覧」116種類（資料12ページ）：https://www.mlit.go.jp/common/001133184.pdf
  - 2020年追加17種類：https://www.mlit.go.jp/report/press/jidosha08_hh_003658.html
  - 2025年追加5種類：https://www.mlit.go.jp/report/press/jidosha06_hh_000159.html
  - 分類番号：https://wwwtb.mlit.go.jp/tohoku/jg/jg-sub29_1.html
  - 従来の1・2桁と0分類：https://wwwtb.mlit.go.jp/tohoku/at/number.htm

## 区切りハイフンと演算記号のデザイン

- 4桁数値の中央の区切りハイフンは薄い緑色にし、横方向の見た目を従来の約60％に縮めます。プレイ画面の配置幅も24pxから14.4pxに縮め、縦位置は中央より6px上に移します。
- タイトルの見本プレートの区切りハイフンにも、薄い色・横方向60％・6px上の調整を適用します。
- ドラッグして配置した演算記号は、従来の中央位置から22px下げ、数字の下半分付近に表示します。演算記号は濃い色を保ち、中央の薄い区切りハイフンと減算記号を明確に区別します。
- 配置済み記号の移動・右クリック削除、平方根や0除算の赤い✕は、移動後の記号位置に追従させます。

### 記号タイルと区切り色の追加調整

- 配置済み記号とドラッグ中の記号にも、パレットと同じ55×53pxの四角いタイル、枠線、背景、角丸、影を付けます。
- 記号のフォントはArial・28pxで統一し、同じ大きさの枠内の中央に揃えます。数字の下半分に置く位置は維持します。
- 区切りハイフンの色は、前回の `#8a9b82` から少し濃い `#6f8567` に変更します。横幅60％と6px上の位置は維持します。
- 平方根の✕はタイルの上、0除算の✕はタイル内の除算記号に重ねて表示します。

## 0を挟む場合の演算記号の必須化

- 0を挟むことで、0以外の数字同士を演算記号なしで加算することはできません。同じ括弧内で、四則演算記号に区切られていない区間には、0以外の数字または部分式を最大1つだけ置けます。
- `1405` に対する `1＋405` は記号不足で無効です。`1＋40＋5` または `1＋4＋05` で正解とします。
- 連続する0や、√・括弧を挟む場合も、非0数字や部分式の間に必要な記号を省略してよい理由にはしません。
- 問題の難易度算定にも同じ条件を適用し、CSVとブラウザー用問題テーブルを再生成します。

## タイトルのクレジットと配置済み記号のドラッグ操作

- タイトル画面の下部に「Produced by DS-Works」を表示します。
- 配置済み記号をナンバープレート下地の外側へドラッグして離した場合は、その記号を削除します。下地内で挿入先がない場所に離した場合は元の位置に戻します。
- 配置済み記号を下部の記号一覧のアイコン上へドラッグして離した場合は、元の配置位置の記号をそのアイコンの記号に置き換えます。パレットの一覧自体は変更しません。
- パレットへの置き換え判定を枠外削除より優先します。先頭の×÷禁止や、括弧を除く桁間2記号までの上限を超える置き換えは、削除せず元の記号を保持します。
- 枠外削除は配置済み記号だけを対象とします。数字やパレットからの新規記号を枠外へ離しても削除・挿入しません。
- 記号の削除・置き換え後は計算結果と正解判定を更新します。

## パレットから配置済み記号へのドロップ

- 下部の記号一覧から配置済み記号のタイル上へドラッグした場合は、新しい記号を追加せず、そのタイルの記号を置き換えます。配置位置・記号の識別子・記号数を保持します。
- 配置済み記号の左右には6pxの余白を設け、タイル外の狭い領域にドロップした場合は、その左右に追加します。隣り合うタイル間では余白が合計12pxになります。
- タイル上への置き換えを桁間への追加より優先し、ドラッグ中は置き換え先のタイルを強調します。
- 先頭の×÷禁止や桁間上限に違反する置き換えは、追加に切り替えず無効にし、元の記号を保持します。

## 追加用余白の拡張と0を挟んだ減算の訂正

- 記号タイルの左右の余白を6pxから18pxに広げます。タイル同士の間は36px、桁間コンテナー両端の追加領域は余白18pxとパディング8pxの合計26pxとします。
- 追加位置の目印として縦の破線を表示し、タイル上の置き換え領域と区別します。
- 加減算に使う0の後で演算記号を省略した場合は、0に適用された符号を次の数字へ引き継ぎます。`8−02` は `8−2＝6` であり、10として正解にしません。`8＋02＝10`、`80−2＝6` とします。
- `8−002＝6` のような連続する0も同じ扱いにし、単項マイナスも考慮します。
- 明示した乗算に使う0と、赤い✕を表示して無視する0除算は従来どおり保持します。例：`8−0×2＝8`、`5×05＝5`、`5÷0＋5＝10`。
- 難易度算定でも0に続く減算の符号を保持し、問題テーブルと解答例を更新します。

## 既存記号の左右への追加位置の強調表示

- 配置済み記号がある桁間では、追加先の背景色・点線を桁間全体へ表示せず、実際に挿入する側の余白だけに表示します。
- 左へ追加する場合は左隣のタイル右端（なければ桁間左端）から対象タイル左端まで、右へ追加する場合は対象タイル右端から次のタイル左端（なければ桁間右端）までを囲みます。
- 初めて記号を置く場合と同じ背景色・点線・角丸を用います。既存タイル自体や反対側の余白は囲みません。
- 強調表示と実際の追加処理は、共通の挿入位置判定を用いて一致させます。タイル上の置き換え表示とは区別し、ドロップ・キャンセル・対象変更時は前の強調表示を消します。

## 中央ハイフンの色の再調整

- タイトル・プレイ画面の中央ハイフンは、数字と同じ色を継承する表示に戻します。横幅60％と6px上の位置は維持します。

- 10問モードでも難易度が進むよう、1～20問目の出題範囲を1問につき50件刻みに変更します。
- 21～50問目は `[1000]～[3999]`、51～100問目は `[4000]～[最後]` とし、いずれも既出インデックスを除外します。
- 上記の範囲は選択した総問題数にかかわらず、現在の問題番号に応じて適用します。

- 1～20問目は、従来の50件刻みを100件刻みに変更します。
- 21～50問目は `[2000]～[4999]`、51～100問目は `[5000]～[最後]` からランダムに選びます。
- 出現済みの値は再出題しません。問題テーブルの値は一意のため、既出インデックスの除外でこれを保証します。

## 演算記号の下地の色分け

- パレット・配置済みタイル・ドラッグ中のタイルで下地の色を統一し、いずれもアルファ値0.5の薄い色を使います。記号の文字や枠全体を半透明にするものではありません。
- ＋は赤 `rgba(245, 144, 144, 0.5)`、－は水色 `rgba(137, 204, 238, 0.5)`、×は黄色 `rgba(247, 221, 107, 0.5)`、÷は黄緑 `rgba(182, 214, 119, 0.5)`、√は紫 `rgba(193, 161, 224, 0.5)` とします。
- 括弧の下地は従来のままとします。ホバーや置き換え先の強調時にも演算記号の色を保持し、枠線・点線で操作対象を示します。
- 記号の置き換え後は、新しい記号の下地色に更新します。

## 画面別BGM

- 全体を落ち着いた曲調に揃え、柔らかい鍵盤音、控えめな低音、持続する和音で構成したオリジナル曲を各画面に用意します。
- タイトル：`/Game/Audio/title.ogg`。72 BPM、約26.67秒。穏やかで親しみやすい長調の曲。
- プレイ：`/Game/Audio/play.ogg`。80 BPM、24秒。考える邪魔をしない、短調を基調とした静かな分散和音の曲。問題ごとに曲を再開せず継続します。
- クリア：`/Game/Audio/clear.ogg`。84 BPM、約22.86秒。明るい長調と上向きの旋律で、嬉しさを表します。
- ゲームオーバー：`/Game/Audio/over.ogg`。64 BPM、30秒。短調と下降する旋律で、残念な気持ちを控えめに表します。
- 各曲は8小節のループ音源で、ステレオ・22,050 Hz・16 bit PCMのWAVとします。残響もループ境界に回り込ませます。
- `/Game/bgm.js` が再生を管理し、画面切り替え時には0.25秒のフェードアウト後、次の曲を0.6秒でフェードインします。基準音量は28％とし、正解ジングルを聴き取りやすくします。
- ブラウザーの自動再生制限に従い、最初のタイトルクリックまたは右上のサウンドボタンで音を開始します。タイトルを開いただけでは自動再生しません。
- 右上のサウンドボタンでBGMと以後の正解ジングルを消音・解除できます。BGMの再生位置は消音しても維持します。
- 外部サービスや追加の音源取得は使わず、ローカルのHTMLを直接開いても再生できる構成にします。

## 操作の効果音

- マウス左ボタンを押したとき、または画面にタッチしたときに、短く軽い決定音を鳴らします。右・中ボタンでは鳴らしません。
- 記号のドラッグによる追加・移動・置き換えが成功したときに、柔らかい設置音を鳴らします。
- 配置済み記号をナンバープレート外へ捨て、削除されたときには、音程が下がるドロップ音を鳴らします。
- 無効な配置、キャンセル、数字の交換では設置音・ドロップ音は鳴らしません。右クリックで配置済み記号を削除した場合も、枠外削除と同じドロップ音を鳴らします。
- Web Audio APIで短い音を合成し、落ち着いたBGMに合う控えめな音量とします。右上のサウンドOFFは効果音にも適用します。

## スマートフォン・タッチ操作への対応

- ドラッグ操作は Pointer Events（pointerdown・pointermove・pointerup・pointercancel）で処理し、マウスとタッチを同じ処理で扱います。複数の指が触れた場合は最初の指だけを操作として扱い、pointercancel ではドラッグを取り消します。
- ページ全体に `touch-action: none` と `overscroll-behavior: none` を指定し、指のドラッグでページがスクロール・拡大しないようにします。長押しメニュー、文字選択、タップ時のハイライトも無効にします。
- 画面全体を `position: fixed` で覆い、アドレスバーの表示・非表示によらず1280×720を16:9のまま画面に収めます。
- タッチ端末（`pointer: coarse`）では、タイトル画面をタップした時点で Fullscreen API による全画面表示を要求し、対応ブラウザでは横向きに固定します。全画面表示や向き固定が使えない場合も通常表示で遊べます。
- iPhone の Safari は要素の全画面表示に未対応のため、ホーム画面に追加した場合に全画面で起動できるよう、`manifest.json`（`display: fullscreen`、`orientation: landscape`）と apple-mobile-web-app 系の meta を用意します。
- タッチ端末を縦向きにしている間は、「端末を横向きにしてお楽しみください」という案内を全面に表示します。
- タッチ操作には右クリックがないため、配置済み記号の削除はナンバープレート外へのドラッグで行います。
- タッチ操作でドラッグ中は、記号が指で隠れないよう、ドラッグ中の記号を指の位置から64px（画面上のピクセル）上に表示します。配置先・置き換え先・削除の判定も表示と同じ位置で行い、見た目どおりの場所に置けるようにします。マウス操作では従来どおりカーソル位置に表示します。

## 4桁未満の問題の上位桁

- 2桁・3桁の問題は、上位桁を0で埋めて4桁の数字として出題します。例：355は `0355`、19は `0019` とします。
- 「・」で表示される上位桁も数字の0として扱い、他の数字と同様にドラッグで位置を入れ替えられます。計算にも0として使います。例：`・×3＋5＋5＝10`。
- 0を「・」で表示するのは、最上位から続く0だけです。並べ替えで途中に移った0は「0」と表示します。例：`・355` の「・」と3を入れ替えると `3055` と表示します。
- 先頭の0は加算記号の省略規則により値を変えずに扱えるため、既存8,866問の出題可否と問題テーブルは変更しません。
