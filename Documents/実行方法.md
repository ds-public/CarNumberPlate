# 実行方法

## ゲームの起動

`/Game/index.html` をChromeやEdgeなどのブラウザーで開いてください。サーバーの起動やパッケージのインストールは不要です。

タイトル画面をクリックし、問題数を選択するとゲームが始まります。

BGMは最初のクリックから再生されます。右上の「♪」ボタンでサウンドをオン／オフにできます。画面ごとに曲が切り替わり、プレイ中は問題が変わっても同じ曲を続けます。

- 数字を左ドラッグして、別の数字と入れ替えます。
- 下のパレットから記号を左ドラッグし、数字の前後や間に挿入します。
- 配置済み記号のタイル上へドロップすると置き換え、タイルの左右の狭い余白へドロップすると追加します。
- 配置済みの記号は左ドラッグで移動、右クリックで削除できます。
- 配置済み記号をプレート外へドラッグすると削除、下部の記号アイコンへドラッグするとその記号に置き換えられます。
- 数字の間には括弧を除いて2記号まで配置できます。
- 0の前後だけ加算記号を省略できます。例：505に＋を1つ入れた式も、5＋0＋5＝10として正解になります。0以外の桁間の記号は必須です（118は1＋1＋8とする必要があります）。
- 初期表示だけでは次の問題へ進みません。数字や記号を操作すると正解判定します。
- 「この問題をリセット」で式を戻せます。残り時間は延長されません。

## 問題データ

- `/Game/Question.csv`：ヘッダーなしの「数値,難易度値」。難易度の昇順、同点では数値の昇順です。
- `/Game/questions.js`：ブラウザー用に同じテーブルを格納した自動生成ファイルです。
- `/Documents/難易度別解答例.json`：各値について、難易度算定に使った式を記録しています。

リポジトリルートで以下を実行すると、問題の抽出から難易度算定、CSVとJavaScriptの同期まで行います。Python 3.10以上を使用します。外部パッケージは不要です。

```powershell
python Tools/generate_questions.py
```

既存の出題値について難易度だけを再計算する場合は、以下を実行します。

```powershell
python Tools/build_question_table.py
```

## 検証

Node.jsで以下を実行します。外部パッケージは不要です。

```powershell
node --check Game/game.js
node Tools/verify_game.cjs
node Tools/verify_interactions.cjs
node Tools/verify_bgm.cjs
```

全8,866問の厳密な計算結果・難易度・桁の使用・記号数・CSVとの同期、出題範囲、重複回避、IQ補間を検証します。画面と入力の検証は模擬DOMを用い、4種類のモードの完走、正解・時間切れ・再挑戦などの遷移を確認します。実ブラウザーの描画や音声を自動検証するものではありません。

BGMの音源は `python Tools/compose_bgm.py` で再生成できます。この音源生成処理に限り、PythonのNumPyが必要です。ゲームの実行にはPythonもNumPyも不要です。
