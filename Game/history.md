# バグ修正履歴

新しいものほど先に記載します。

## Version 1.0.1

- 2026/10/31 09:29  
  数字 0 を掛けた項（0×1 など）の前後で＋を省略できなかった問題を修正。  
  01 25 は 0×1＋2×5 としないと正解にならず、25 01 の 2×5 0×1 と  
  扱いが異なっていた。0×1 などの項は存在しない値として扱い、  
  0 と同じく前後の＋を省略できるようにした。

- 2026/10/31 08:55  
  ・が 0 として扱われなかった問題を修正。  
  2桁・3桁の問題の「・」をドラッグで並べ替えできず、  
  計算にも 0 として使われていなかった。  
  途中へ移した 0 は「0」と表示する。
