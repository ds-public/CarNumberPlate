# バグ修正履歴

新しいものほど先に記載します。

## Version 1.0.2

- 2026/11/02 21:07  
  記号を置いても中央の区切りハイフンが残り、減算記号と  
  紛れやすかった問題を修正。記号を1つ以上置いている間は  
  ハイフンを表示しないようにした。あわせて記号の位置を  
  数字の下端に揃え、「この問題をリセット」の表示を削除。

## Version 1.0.1

- 2026/11/02 08:47  
  ダブルクリック削除の2回目で決定音も鳴っていた問題を修正。  
  2回目の押下で決定音とドロップ音が重なっていた。  
  配置済み記号への2回目の押下では決定音を鳴らさず、  
  ドロップ音だけを鳴らすようにした。

- 2026/11/01 11:55  
  プレートの色に対してありえない分類番号が表示される問題を修正。  
  黄・黒（軽自動車）でも 1・2・3・9・0 で始まる番号や、  
  1桁の番号が表示されていた。黄・黒では先頭が 4～8 の  
  40・50・80 と 400～899 だけから選ぶようにした。

- 2026/10/31 09:29  
  数字 0 を掛けた項（0×1 など）の前後で＋を省略できなかった問題を修正。  
  01 25 は 0×1＋2×5 としないと正解にならず、25 01 の 2×5 0×1 と  
  扱いが異なっていた。0×1 などの項は存在しない値として扱い、  
  0 と同じく前後の＋を省略できるようにした。

- 2026/10/31 08:55  
  ・が 0 として扱われなかった問題を修正。  
  2桁・3桁の問題の「・」をドラッグで並べ替えできず、  
  計算にも 0 として使われていなかった。  
  途中へ移した 0 は「0」と表示する。

## Version 1.0.0
